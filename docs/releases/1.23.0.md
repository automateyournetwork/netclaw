# NetClaw 1.23.0

Spec: [194-rag-structured-ingestion](../../specs/194-rag-structured-ingestion/spec.md)

## Changes

The RAG knowledge base accepts JSON files and URL responses. OpenAPI and Swagger operations can be cited by method and path. URL preview identifies likely JavaScript shells and reports visible text length. Local HTTPS appliances can negotiate HTTP/2 through system curl.

## Upgrade and compatibility

Existing calls verify TLS by default. For a user-approved exception on a self-signed service, pass verify_ssl=false on each request. Existing indexes require no migration.

## Validation and known limitations

See [verification](../../specs/194-rag-structured-ingestion/verification.md) for isolated parser and URL tests. The fetcher extracts static content and does not render JavaScript.
