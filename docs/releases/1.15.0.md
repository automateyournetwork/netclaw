# NetClaw 1.15.0

Spec: [162-convergence-read](../../specs/162-convergence-read/spec.md)

## Changes

Add an optional Convergence connector with two read-only MCP tools and a HUD view
for retained flow summaries and exact-window records. Coverage labels distinguish
synthetic demo, host and network evidence. The service remains separately deployed;
no collector, database or chart is added to NetClaw. See the [connection guide](../CONVERGENCE.md).

## Upgrade and compatibility

Disabled by default. Existing installations require no migration. Install the optional
`convergence-read` component, configure a dedicated site-scoped viewer key and
regenerate its native MCP registration as documented. Repeating installation preserves
private configuration. Disabling and regenerating registration stops reads without
deleting external data. The connector requires Python 3.12 or newer.

## Validation and known limitations

The [verification ledger](../../specs/162-convergence-read/verification.md) records
contract, HUD, browser and disposable service integration evidence. Local Linux
amd64 demo and host export paths passed through retained storage, generated MCP
registration and the HUD, including repeat installation, disable and restart
persistence. Native Linux amd64/arm64 CI is defined separately. macOS, WSL2, Hermes,
a full OpenClaw gateway/model turn and physical network capture are not qualified
by these tests. Latest-record samples do not reconstruct aggregate totals.
