# NetClaw 1.15.3 — native migration rehearsal fixes, unpublished

reference JSON files in a new installation, gateway authentication with native
environment SecretRefs, dynamic pyATS state disappearing when OpenClaw closes
STDIO after a turn, and an agent replacing a captured baseline with a reference note.

baseline bytes against the retained original before configuration.

An optional explicitly started foreground pyATS session now preserves inventory
across turns using a private descriptor and authenticated loopback transport.
The original tools and candidate approval controls remain in force. Restart
requires fresh composition, validation, activation and review. See
[dynamic testbeds](../DYNAMIC-TESTBEDS.md).

private running baselines through NetClaw. The clean protected application repeat
passed OSPF FULL, metric-11 reciprocal routes, 5/5 positive and 0/3 negative pings
in both directions, with management preserved. T034 fresh native installation
acceptance is the sole remaining task (43/44). Failed bootstrap and legacy SSH trials
remain in the evidence. Source tests and real appliance behavior are recorded
separately in [Spec162 verification](../../specs/162-netconverterai/verification.md).
No Junos appliance qualification, production rollout or publication is implied.

Verification: 69 NetConverter tests; 9 managed pyATS/session tests against the
actual pinned runtime; 10 focused Node checks; 274 setup tests with 32 optional
skips. The original partial installer journal is preserved alongside scoped
