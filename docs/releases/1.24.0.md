# NetClaw 1.24.0

Spec: [195-production-integrations](../../specs/195-production-integrations/spec.md)

## Changes

Operators can select GreyNoise Community for public IPv4 reputation lookups and install the community threat intelligence server at a reviewed revision. Both integrations use normal MCP registration and tool discovery. Catalog checks and Claw Plan can also read MCP templates that include decimal provider prices.

## Upgrade and compatibility

Enable the optional components using their installer IDs, `greynoise-community` and `threatintel`. Supply provider credentials through the runtime environment for the operations that require them. Existing deployments that registered either server by hand should review their launch commands during migration.

## Validation and known limitations

Checks cover MCP startup and tool discovery, deterministic provider responses, template validation and RAG retrieval. Credentialed provider access depends on the operator's API entitlements. See the [verification record](../../specs/195-production-integrations/verification.md).
