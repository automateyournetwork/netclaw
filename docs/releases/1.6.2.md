# NetClaw 1.6.2

Spec: [147-installer-followups](../../specs/147-installer-followups/spec.md)

## Changes

Installer follow-up from the macOS and Linux first-use reports. Builds on Nick's
merged host-preflight/Zabbix repair and the dotenv preservation fix.

- Enforces one runtime-specific Node policy and npm-version-aware lifecycle script
  handling. Uses a user-owned prefix when the global prefix is unwritable; runtime
  installation/executable failures stop the installer.
- Registers thirteen native MCP servers for the twelve reported missing components.
  Native and recognized skill calls share recorded Python interpreters, module
  paths and explicit stdio transport. pyATS keeps its private HTTP bridge.
- Reports artifacts, registration, discovery, configuration requirements and provider
  readiness separately. Empty/failed probes cannot masquerade as working tools.
- Checks configured local/remote Ollama model availability and advertised tool
  support without requiring a local CLI for remote use or downloading models.

## Upgrade and compatibility

Pull main and rerun `./scripts/install.sh --add "<your component ids>"` with the same
runtime selection. Existing credentials, custom registrations, persona files and
approval controls remain preserved. Old global packages are not purged. Custom
launch conflicts stop deployment for manual reconciliation.

OpenClaw requires Node `>=24.16.0 <25 || >=26.1.0` for the declared current target;
Hermes retains its own component Node floor. See [readiness and recovery](../INSTALLER-READINESS.md).
No tag or published release is created by preparing these source release notes.

## Validation and known limitations

[Verification](../../specs/147-installer-followups/verification.md) records unit,
reconciliation, actual native discovery and a local calculator canary. Test package
installation used a disposable environment; no operator gateway or device changed.

Original live CML/pyATS access, the six unnamed macOS failures and arbitrary model
answer grounding remain unverified. Hermes native agent discovery is not certified;
its direct stdio probe is labelled accordingly. A successful tool listing proves
neither endpoint credentials nor a completed agent turn.
