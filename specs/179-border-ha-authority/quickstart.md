# R08 development and acceptance sequence

This is maintainer qualification guidance,not a public deployment recipe.

1. Confirm179branch/spec and active GAIT;readspec/plan/contracts/tasks.
2. Use a fresh owned private root and exact source/image hashes;baseline retained
   owner resources/retirement receipts. Do not load historical activation payloads.
3. Run contract and standalone regression tests,then create the reviewed isolated
   three-voter/three-Border fixture with independent peer/client trust and RBAC.
4. Qualify positive control and every fault row;export each significant run.
5. Review fixture gate before starting the fresh actual OpenClaw/DefenseClaw/
   Ollama/nativeMCP profile with finite operation/model/tool bounds.
6. Prove real admission/fencing,original signed result/ACK and no-repeat recovery.
7. Exercise actual browser,isolatedCode1.109,nativeiOSsimulator over that same state.
8. Run affected broad regression/coherence checks;export/hash private evidence.
9. Retire only listed owned resources;verify actual absence;keep evidence/unknowns.
10. Present evidence/measurements and acceptance packet;stop beforeR09.

Exact commands and observed outputs are added to runbook.md/verification.md as
implementation supplies them. This sequence is not evidence that any step ran.
