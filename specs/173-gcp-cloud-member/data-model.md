# R04 data model

Reuse signed envelopes and SQLite ledgers; no alternate authority store.

- Workload selection: member, tool, exact arguments, safe device_ref target label,
  runtime/model/MCP/schema/skill revisions. Explicit NetBox type/positiveID or
  bounded calculator network; unknown keys, ambiguity and drift refuse.
- Source binding: exact verified HTTPS origin and private member credential reference;
  no browser/model-supplied URLs. Captures carry time, objectID and response digest. Remote record changes consume
  the authorized read; only local pin drift can refuse before it.
- Role: existing Border preserved; member control_only=false, no HUD origin,
  one outbound direct registry binding, enrollment generation, immutable closures.
- Attempt: existing prepared/approved/admitted/running/result-or-unknown/ACK states.
  Unknown remains spent; availability changes do not authorize another effect.
- Browser reference: bounded installation/operation identity; no secrets, approval
  capability or raw result persisted. Display facts only from verified evidence.
- Cloud packet: fresh exact plans, resource/source/image hashes, secret version
  references, costs/expiry, preservation and teardown receipts. State stays private.
