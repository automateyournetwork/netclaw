# NetClaw 1.15.0 — source milestone, unpublished

Spec: [162-netconverterai](./spec.md). Coordinated VS
Code extension source: **1.5.0**. This records implemented source and qualification
limits; it is not a published release or a successful live migration claim.

## Changes

Optional NetConverter setup selects hosted read-only access or an operator-installed
licensed Terminal. The NetClaw guard discovers account capabilities, prepares a
private file snapshot and requires native approval of the exact digest before one
hosted submission attempt. Unknown outcomes never permit automatic resubmission.
The installer installs guard dependencies only; it does not accept the Terminal
license, borrow another account or upload a configuration.

Private pyATS collection and candidate application retain the existing tool
identities. Terminal Intent binds one reviewed file to one explicitly designated
SSH endpoint, same-process inventory and actual Local/Lab API change record.
Baseline/rollback preparation precedes a short-lived one-use apply capability.
Cancellation and evidence-storage faults preserve uncertain outcomes for inspection.

The new migration skill composes inventory, NetConverter, CML/containerlab/EVE-NG/
GNS3, pyATS, scoped Batfish analysis, optional Jev review and local evidence drafts.
Actual targets require compatible licensed images, capacity, management/bootstrap
and existing configuration authorization. FRR peers do not establish a supported
converter target. Batfish partial parsing and query failures remain inconclusive.

## Compatibility and qualification

Use matching source 1.15.0 and extension 1.5.0 for the new installer selection.
Updating either does not upgrade existing runtime homes or device configurations.
NetConverter's managed submission path currently qualifies text input with explicit
vendor roles/device class; non-text/archive handoffs, missing legacy metadata and guided-draft
mutations are unavailable. Junos private application requires set lines without
semicolon/pipe separators. Live Junos collection/commit remains unqualified.

[Verification](./verification.md) records controlled
official-SDK, installer, API issuer/consumer, UI, pyATS and Batfish checks and
[five explicit review iterations](./ralph-iterations.md).
The free account is awaiting enablement; licensed-client/account discovery,
exact-file-approved real conversion, native desktop/platform acceptance and the
image-backed Junos rehearsal remain open. No real configuration has been uploaded
or applied by this milestone. Existing owner-runtime reconciliation failures are
reported separately from feature checks.
