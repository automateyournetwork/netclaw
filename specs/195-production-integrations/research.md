# Integration baseline

The RAG behavior used during qualification is specified in spec 194. Runtime configuration uses component interpreter records and native OpenClaw MCP registrations. A shell that sources a repository-local environment would introduce a second configuration authority. Register the server process directly and inherit configured credentials.

The upstream template currently contains no fractional model prices. Catalog and Claw Plan code uses the plan schema loader for the entire template, so an unrelated provider price can prevent the MCP registrations from being read. Validate the selected subtree at the boundary.

The contract runner checks its inventory against test directories. The existing GCP suite was absent from the inventory, which prevented expanding the CI matrix for all components.
