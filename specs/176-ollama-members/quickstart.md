# Quickstart: implementation handoff, not deployment instructions

1. On `176-ollama-members`, read [spec.md](spec.md), [research.md](research.md) and
   both [contracts](contracts/). Use `thermidor-reference.json` to verify adopted
   bytes in the sibling checkout. Start with final Spec004 evidence, not early candidates.
2. Implement [tasks.md](tasks.md) in dependency order. Native subnet tools remain
   the execution path; Thermidor arithmetic validates their results independently.
   Profile changes do not widen existing hosted/IPv4 contracts.
3. Run the focused test groups named in tasks. Mark fixture/source results as such.
   Qualify the actual selected guard and native MCP before any model run. Model
   canaries consume a real finite approval/call budget; never retry unknown ones.
4. Prepare the reviewed owned runtime packet before activation: host capacity,
   resource identity/expiry, baseline, rollback, private artifacts, exact changes,
   existing delegation, preservation and cleanup/retention. Keep the intended owner
   deployment usable. Never replay an old R03/R04/R04a/R04b activation artifact.
5. In the actual HUD, request IPv4 `192.0.2.0/26` locally plus IPv6
   `2001:db8:1234::/48` in cloud. Check both reviews; approve each separately.
   Independently verify IPv4 network/broadcast `.0/.63`,64 total/62 usable addresses;
   IPv6 total `1208925819614629174706176` addresses and65,536 contained `/64`s.
6. Confirm each success used2 actual inference turns and1 native MCP call, signed
   results/ACK, measured usage and no paid provider call. Run the isolation, failure,
   unknown/restart and status-only recovery matrix, preserving original effect counts.
7. Repeat required flows in actual Mac VS Code and native iPhone simulator; record
   distinct G12/G13 evidence and preserve the existing connection/device identity.
8. Complete [verification.md](verification.md), export evidence, retire only disposable
   resources, record retained delivery and request the human R05 evidence gate.
   R06/R07 and release/public rollout remain separate.

Historical Thermidor28s/150s times are comparison points, not expected exact timings.
There are no R05 launch commands or reusable live approval payloads in this package.
