# Observable quality bar

“Perfect and amazing” is a direction for refinement,not a measurable guarantee.
Use these observable checks and retain defects until corrected:

1. Exact local SVG graph:real identity bindings,full interfaces,evidence-backed
   edges,uncertainty/staleness,readable non-overlapping labels,pan/zoom/fit,
   selection→provenance,no invented adjacency or hidden failures.
2. Creative local3D view:the same immutable graph rendered as a coherent blue/amber
   network diorama,distinct routing/switching forms,visible interface endpoints,
   links physically attached to correct ports,local lighting/status legend. Styling
   cannot add/remove edges. All assets local;no external image subscription.
3. Walkthrough:actual keyboard/camera navigation between reachable points of
   interest,clear overview/reset,focus and key-release behavior,visible stop/exit,
   readable device/interface/counter overlay outside generated pixels. A fixture
   screenshot alone does not prove navigation. Record actual browser interaction.
4. Data:real bounded CDP/LLDP capture with source/interval,one-sided/conflicting
   links,empty versus unavailable states. Counter deltas/rates require valid
   paired samples and continuity;unknown never becomeszero. No silent polling.
5. Google:actual synthetic generated world,>=10s navigation,one visible fictional
   event within the declared bound,three-checkpoint counts/link drift review,
   provider terminal receipt and usage. Preserve visual failures. No claim of
   persistent editable3D scene graph or topology accuracy from generated frames.
6. Safety/lifecycle:private local graph never hosted,credential/backend separation,
   exact one-attempt grant,backend deadline,duplicate/restart/disconnect/unknown
   outcomes retained. No new ID/account alias bypass. No provider key in browser.
7. Native integration:one real isolated NetClaw uses the installed skill and MCP,
   with correlated worker/operation/evidence IDs;tool discovery alone does not pass.
8. Review:for changed UI inspect actual synthetic screenshots at1280x900 and a
   narrower desktop viewport,verify keyboard controls,contrast/readability,
   provenance and selected-state feedback. Do not upload private screenshots.
9. Coherence:changed-component regression,catalog/installer/docs consistency,
   explicit VSCode/Mobile limits,no premature release or changes to owner runtimes.
10. Owner acceptance:show actual evidence and record the owner's verdict. An agent
    review cannot close T029.100% requires every task's actual exit conditions.

Refinement is evidence-led:implement→exercise→inspect→identify specific defect→fix.
Never generate extra paid sessions solely to chase vague aesthetic perfection.
