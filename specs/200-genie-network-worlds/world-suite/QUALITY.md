# Observable quality for five Genie-4 worlds

Every world must use identical measured device/interface/link identities and
snapshot provenance; routing/VLAN/STP layers remain distinct from physical links.
All captured values are historical, with SW1 enrichment failure/host gaps visible.
A source pass is not a world. Acceptance requires actual Google provider identity,
>=10seconds deliberate navigation, baseline/navigation/event captures, one visible
fictional state-change, drift/recognizability review, terminal receipt and usage.
Readable authoritative facts stay outside generated pixels; no invented precise
labels/object persistence. Clickable local inspection and provider text actions
have separate semantics. Unknown stop/usage prevents replacement paid creation.

Evaluate legibility, sense of place, four recognisable roles, three traceable
inter-device connections, distinct style, coherent navigation/revisit, believable
lighting/materials, measured-versus-fiction clarity, focus/key-release/stop,
private credential boundary and bounded latency. No promise of perfection.

Member-in-a-Risk acceptance needs actual member identity, scoped snapshot access,
installed skill, execution MCP/tool correlation and backend-owned session/stream/
termination. Tool discovery or direct API proof alone does not pass that gate.
No global authority, automatic device re-query or new Border component is needed.
