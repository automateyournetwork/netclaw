# Lifecycle and HUD contract

All launch surfaces resolve the shared selection precedence (explicit matching-runtime overrides, private persisted descriptor, legacy OpenClaw default). Pass canonical home/config/env, installation identity, federation base and selected endpoint explicitly into children. Do not source dotenv as shell code or inherit another installation's provider credentials.

Explicit daemon/member start owns the federation companion and broker. Status/discovery performs no inference or startup. Verify selected installation identity before reusing any listener. Store private keys/manifests atomically with owner-only modes, reject unsafe symlinks, retain populated owner files. Stop only a verified owned process/unit; never global pkill. Bind before declaring readiness; port collisions never kill their owner.

Hermes member provisioning copies only selected model/provider metadata, scoped qualified registrations and reviewed skills. Credentials go to private .env, never cards or runbooks. Children get fresh required process environment plus member-specific settings. Service/lock names include installation identity; a managed member cannot also cold-start. Missing service manager must not mark a member managed. Actual effective production confinement/model guard determines posture; no silent bare-process fallback.

Hermes HUD federation capability is readiness-driven. `/api/n2n` and `/api/bgp` read/act against the matching selected daemon; reject identity mismatch. Preserve independent denials for Terminal Intent/write/hosted Avatar/etc. Render harness, model, tool eligibility, task provenance/uncertainty and current posture without false zero or stale-success claims. Existing Chat/Canvas/Avatar storage/ownership remains unchanged.

Shared knowledge, replication, edge and channel call sites are inventoried. Preserve runtime-neutral functions; explicitly reject unqualified Hermes agent ingress rather than sending it to OpenClaw. No new mobile/media/channel feature is claimed.
