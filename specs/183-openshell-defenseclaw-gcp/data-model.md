# Data Model: R09A

- **Sandbox** (`netclaw-node` per node): `name`, `node_code`, `image_digest`, `policy_version`, `policy_sha256`, `landlock` (`hard_requirement`), `phase` (Ready/Error), `components[]`.
- **Component**: `name` (border-role, hud-ingress, workspace-backend, chat-gateway, defenseclaw-sidecar), `inside_sandbox` (bool), `disposition` (inside | outside-with-reason), `state`.
- **Sandbox Policy**: YAML (version 1) with `filesystem_policy`, `landlock`, `process`, `network_policies`; generated by `labs/ha/r09a_policy.py` from a node spec; versioned by content hash. Rules: default deny; peers as `protocol: tcp` + `tls: skip`; Anthropic as HTTPS with provider credential injection (default TLS termination); metadata server never listed.
- **Guardrail Policy**: DefenseClaw config derived byte-for-byte from the qualified R04A Anthropic file; `mode` (`observe` | `action`), `hook_fail_mode: closed`.
- **Audit Record**: DefenseClaw SQLite row (blocked prompt/tool, policy change, guard state) plus OpenShell OCSF events (`NET:OPEN/FAIL`, `CONFIG:PUBLISHED`); exported per node.
- **Node Posture** (served read-only): see [contracts/node-posture.md](contracts/node-posture.md).
- **Negative Test**: `id`, `attempt`, `expected` (refused + record), `observed`, `evidence_ref`.
- **Forward**: host `bind:port` to sandbox loopback port (cluster 7443, in2n 7444, ingress 8443 with host 443 redirect).
