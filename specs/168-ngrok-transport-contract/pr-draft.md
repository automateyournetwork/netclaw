# R01 experimental transport source (no release)

A cloud Border can use direct TCP while on-prem members dial outward, with the
existing optional ngrok path preserved. Routing addresses, verified TLS names and
application identities are independent. TLS1.3/exporter proofs, revocation,
protocol refusal, owned lifecycle and revision-checked relocation fail closed.

The isolated owner pilot demonstrated cloud-to-Mac iN2N tool execution and full
HUD Chat/Canvas/RAG. Keep that lab evidence distinct from production, platform and
multi-user qualification. Public rollout guidance/cards are deferred; the source
is merged for continued maintainer work, with no R01 version bump, release, tag,
Marketplace publication or announcement until the whole issue310 roadmap is done.

Preserves upstream OpenClaw fixes/version1.18.1. Validation and retained skips
are in verification.md and main-integration.md. R02 execution parity is next;
users/SSO/RBAC remain R15–R17. No running installation is upgraded by this PR.
